# Проверка демонстрации

Проверено локально 8 октября 2026 года: Windows, .NET SDK 10.0.401, Chrome. Сборка Release; браузерный сайт запускается через HTTP под тем же префиксом пути, который используется на GitHub Pages.

- Ядро собирается и тестируется как обычная .NET библиотека.
- WebAssembly публикуется с partial trimming, без AOT. При сборке есть предупреждения IL2040 о ресурсах оптимизационных метаданных FSharp.Core; успешная сборка не называется сборкой без предупреждений.
- Холодный запуск в Chrome доходит до вызова F# и выдаёт результат вычисления.
- Проверены широкая компоновка и начало страницы в iframe шириной 390 px. Это проверка адаптивной вёрстки, не тест физического мобильного устройства или Safari.
- Полный каталог опубликованного сайта занимает около 21 MiB без транспортного сжатия; фактический объём сетевой загрузки не измерялся.
- Новый workflow задаёт тесты Windows/Linux и публикацию Pages. Актуальный результат CI находится во вкладке Actions; локальный результат не заменяет CI.

## Ядро

25 тестовых случаев: сохранение заявок, ограничения очередей и ресурсов, граничные вероятности, независимость поступлений от штата, повторяемость, временная сетка, ограничения параметров и усреднение всех прогонов.

Команда: `dotnet test lab/Tests/Tests.fsproj -c Release`.

## Браузер

Ручной сценарий через элементы интерфейса: «Наплыв заявок» → «Запомнить для сравнения» → «Усилить команду».

При seed 42, 12 прогонах по 8 часов, потоке 45/ч, среднем обслуживании 4 минуты, четырёх исполнителях приёма и буфере 6 увеличение штата каждой ветви с одного до двух дало:

| Показатель | До | После |
|---|---:|---:|
| Завершено в среднем | 233,3 | 345,3 |
| Доля потерь | 31,8% | 2,7% |
| Время завершённой заявки | 26,8 мин | 13,5 мин |
| Осталось в работе | 15,2 | 9,3 |

Это наблюдённый результат выбранной учебной модели, не эмпирическая оценка бизнеса. В консоли Chrome ошибок при запуске не наблюдалось.

Исторические приложения Aivika/GTK не запускались и этими проверками не покрываются.
