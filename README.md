# Поток — лаборатория очередей на F#

**Что произойдёт с очередью, если заявок станет больше, а исполнителей останется столько же?** Интерактивная модель позволяет изменить поток, размер команды и буфер очереди, затем сравнить потери, время обработки и загрузку.

## Попробовать за минуту

1. Откройте «Наплыв заявок» и нажмите «Запомнить для сравнения».
2. Выберите «Усилить команду»: изменятся загрузка, число завершённых заявок и доля потерь.
3. Раскройте дополнительные параметры: распределение времени обслуживания, длительность и seed.
4. Скачайте JSON с параметрами и результатами — эксперимент можно воспроизвести.

При первом открытии загружается .NET WebAssembly. Расчёт выполняется **на F# в браузере**, без серверного API, регистрации и установки приложения. JavaScript отвечает за форму и графики.

## Что здесь реализовано

- Дискретно-событийная модель: приём → одна из двух ветвей обработки, FIFO-очереди, ограниченные буферы ветвей.
- Календарь событий со стабильным порядком, отдельные потоки случайных чисел для поступления, маршрутизации и обслуживания.
- Повторяемые прогоны, средняя загрузка и длина очереди, время обработки, потери, график первого прогона.
- Баланс заявок: поступило = завершено + потеряно + осталось в системе.
- 25 автоматических тестовых случаев, включая разные seed и распределения, границы очередей и усреднение статистики.

Модель помогает **исследовать гипотезы** о пропускной способности службы поддержки, обработки заказов или другого процесса. Реальные решения требуют калибровки по данным; результаты демо не являются прогнозом конкретного бизнеса.

## История и современная версия

Это репозиторий учебных работ ИТМО. Исторические проекты на F#/.NET Framework используют Aivika и GTK; их исходники и история сохранены.

В каталоге `lab/` находится **новое переносимое ядро на .NET 10**, которое воспроизводит топологию исходной простой модели. Это отдельная реализация, а не перенос Aivika в WebAssembly и не подтверждение работоспособности всех старых проектов. Сложная модель найма из курсовой не включена в браузерную демонстрацию.

## Запуск разработчиком

Нужны .NET SDK 10 и PowerShell 7 для сборочного скрипта.

```powershell
dotnet test lab/Tests/Tests.fsproj -c Release
./Build-Lab.ps1 -BasePath /
```

Статический сайт окажется в `artifacts/site`. Откройте его через HTTP-сервер, например `python -m http.server 8080 --directory artifacts/site`; запуск через `file://` не поддерживается.

GitHub Actions проверяет ядро на Windows и Linux, собирает сайт и публикует ветку `master` в GitHub Pages.
